🐕 LeakHound

A fast, local pre-commit secret scanner powered by entropy and regex.

Open Source • Python CLI • DevSecOps

Quick Install

git clone https://github.com/YOUR_USERNAME/leakhound.git
cd leakhound
pip install -e .
./install_hook.sh

Dual-Engine Detection

Catches known API signatures (AWS, GitHub, Slack) as well as unstructured high-entropy strings using Shannon entropy math.

Zero Third-Party Leaks

Runs 100% locally on your machine prior to Git commit staging. No files or hashes are transmitted across the network.

Usage

# Scan a single file or directory
leakhound --path ./src

# Scan currently staged git files
leakhound --staged

# Customize entropy threshold (default: 4.3)
leakhound --path . --threshold 3.8
